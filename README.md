#Complex Fantasy Simulation Game

##*Description*
>This project is a video game heavily inspired by dwarf fortress, with less focus on
emotions and consciousness, but more on ressources diversity and world interactions.

##How to understand this repository
Right now, there are no code. You can check the work in the docs/ folder. Classes are
grouped in files which include one another and they each contain attributes and methods
detailed in the uml files.  
You can follow the ideas, see the future features, understand how the code will function
and note down the future updates planned by looking at the markdown files.
